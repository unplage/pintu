# 🧩 巨幕拼图工坊 (pintu)

三模式益智拼图 PWA · 全屏自适应 · 智能辅助 · 离线可玩

在线试玩：https://unplage.github.io/pintu/

---

## 🎮 玩法

上传图片或选用内置演示图，选择模式与难度，还原图像即可获胜。

### 三种游戏模式

| 模式 | 玩法 | 胜利条件 |
|---|---|---|
| 🧩 交换拼图 | 点击或拖拽两块交换位置 | 全部碎片归位 |
| 🎯 滑动拼图 | 点击空位同行/列任意碎片滑动 | 空位移到右下角 |
| 🔄 旋转拼图 | 点击碎片原地旋转 90° | 全部转正 |

> 滑动模式打乱时经过奇偶置换校验，**保证必然可解**。

## ✨ 功能特性

- **非正方形网格**：行列各 2–8 自由设置，或使用难度预设（简单 3×3 → 大师 6×6）
- **计时评级**：实时计时、步数、完成进度条，通关后按用时/步数/提示数评定 1–3 星
- **智能提示**：一键高亮所有未归位碎片并计数
- **撤销**：支持逐步回退（按钮 / `Ctrl+Z`），上限 50 步
- **拖拽交换**：交换模式支持点选与拖拽两种交互，带平滑位移动画
- **进度反馈**：已归位的碎片显示绿色光晕
- **最佳战绩**：按「模式 × 尺寸」记录最佳用时、最少步数、星级、对局与胜场
- **成就徽章**：首胜、零提示通关、60 秒通关、3 星、累计 10 胜、5×5 以上通关等 8 枚
- **内置演示图库**：4 张 canvas 生成图案（落日 / 几何 / 森林 / 波光），离线可用
- **高清渲染**：按 devicePixelRatio 缩放绘制，大屏清晰
- **音效系统**：交换/滑动/旋转/撤销/提示/胜利等差异化 WebAudio 音效，可开关
- **庆祝效果**：通关时彩纸粒子 + 星级弹层 + 胜利音效
- **键盘快捷键**：`Ctrl+Z` 撤销、`R` 新一局、`H` 提示
- **PWA 离线**：Service Worker 预缓存，断网可玩

## 📂 项目结构

```
pintu/
├── index.html    # 单文件应用（HTML + CSS + JS 全部内联）
├── manifest.json # PWA 清单
└── sw.js         # Service Worker 离线缓存
```

无构建工具、无第三方依赖（图标与演示图均程序生成），直接打开或本地起服即可：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 🛠 技术要点

- **单文件 PWA**：全部逻辑内联于 `index.html`，无模块系统
- **滑动可解性**：Fisher-Yates 打乱 + 奇偶置换校验（宽为奇数看逆序数奇偶，宽为偶数还需加上空位行距）
- **动画**：requestAnimationFrame 插值实现碎片滑动/交换过渡
- **持久化**：`localStorage` 存储战绩与成就（`pintu_records_v1` / `pintu_achievements_v1`）
- **演示图**：canvas 2D 程序绘制，`toDataURL` 转图片，无需网络
